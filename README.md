# Sanja Radakovic — Portfolio

A minimal, editorial portfolio site — ivory, linen and espresso tones, Cormorant Garamond + Jost.

Plain HTML, CSS and JavaScript — no build step.

- `index.html` — content (projects, copy, links)
- `styles.css` — design
- `script.js` — scroll reveals and project accordion

## Editing projects
Each project is an `<li class="project">` in `index.html`. Change the title, tags or description there.
To link a case study, replace the `<span class="detail-meta">Case study — coming soon</span>` with
`<a class="detail-meta" href="YOUR-LINK" target="_blank">View case study →</a>`.

## Hosting
Served with GitHub Pages from the `main` branch.
